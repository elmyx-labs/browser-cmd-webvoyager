FINAL: For a new paid individual subscription, GitHub currently lists Copilot Pro at US$10 per month—US$120 for 12 months at that rate.

As checked on October 28, 2026, its main features include:
- Unlimited code completions and next-edit suggestions.
- Copilot Chat in supported IDEs, on GitHub and GitHub Mobile, plus inline chat and slash commands.
- Model selection and access to medium-complexity models.
- Agent mode, Copilot cloud agent, and code review.
- Access to third-party agents such as Claude Code and Codex.
- Copilot CLI, the Copilot app, and community support.
- Custom instructions and agents, MCP integrations, Copilot Spaces, and a public-code filter with code referencing.
- Currently 1,500 AI credits per month ($15 usage value), including 1,000 base credits and a variable 500-credit flex allotment. Extra usage can cost more; unused credits do not roll over.

GitHub now presents several individual plans rather than a single plan named “Copilot Individual.” The price above is for the entry-level paid plan, Pro. Existing annual subscriptions are covered by legacy billing terms; the current price for a new subscription is monthly.
