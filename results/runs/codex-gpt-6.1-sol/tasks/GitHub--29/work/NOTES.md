GitHub Pricing — https://github.com/pricing — Free: “Unlimited public/private repositories”. Current pricing comparison lists Free, Team, and Enterprise.
GitHub's plans — https://docs.github.com/en/get-started/learning-about-github/githubs-plans — “With GitHub Free for personal accounts, you can work with unlimited collaborators on unlimited public repositories with a full feature set, and on unlimited private repositories with a limited feature set.” Under GitHub Pro: “In addition to the features available with GitHub Free for personal accounts, GitHub Pro includes:”. Thus Pro also allows unlimited private repositories.
