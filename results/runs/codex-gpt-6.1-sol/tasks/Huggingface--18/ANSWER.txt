FINAL: TRL’s “Reward Modeling” documentation explains this under “Adding a margin to the loss”: add a `margin` column to the dataset. The reward collator automatically passes it through, and the loss is computed accordingly.

The documented example uses the chosen score minus the rejected score:

```python
def add_margin(row):
    return {"margin": row["score_chosen"] - row["score_rejected"]}

dataset = dataset.map(add_margin)
```
