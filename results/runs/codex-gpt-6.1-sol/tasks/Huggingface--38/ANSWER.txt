FINAL: In Hugging Face Transformers, add new vocabulary entries with tokenizer.add_tokens(...), then resize the model's token embeddings to len(tokenizer).

The English tokenizer API documentation, version v5.21.0, was checked on October 27, 2026.

Example adapted from the documentation:
    from transformers import BertTokenizerFast, BertModel

    tokenizer = BertTokenizerFast.from_pretrained("google-bert/bert-base-uncased")
    model = BertModel.from_pretrained("google-bert/bert-base-uncased")

    num_added = tokenizer.add_tokens(["new_tok1", "my_new-tok2"])
    model.resize_token_embeddings(len(tokenizer))

add_tokens accepts a string, an AddedToken, or a sequence of either. It adds only entries absent from the vocabulary, appends new entries to the end, and returns the number actually added. AddedToken lets you customize matching and whitespace behavior. The special_tokens argument defaults to False.

The resize call must receive the full updated tokenizer length, rather than num_added. The documentation explicitly demonstrates model.resize_token_embeddings(len(tokenizer)).

For a token with a special role, use a dictionary with add_special_tokens:
    tokenizer.add_special_tokens({"cls_token": "<CLS>"})
    model.resize_token_embeddings(len(tokenizer))

This also registers the role as a tokenizer attribute (tokenizer.cls_token in this example). The add_special_tokens documentation explicitly states that special tokens are "never split"; they can also be omitted during decoding with skip_special_tokens=True.
