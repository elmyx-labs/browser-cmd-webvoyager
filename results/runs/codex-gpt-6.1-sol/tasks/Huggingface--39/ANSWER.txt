FINAL: To train on a custom dataset, preprocess it for your model, configure TrainingArguments, pass the model and datasets to transformers.Trainer, and call trainer.train(). The inspected Trainer constructor has 13 configurable parameters, listed below.

Using your own dataset
1. Supply a Hugging Face datasets.Dataset or a compatible PyTorch Dataset; an IterableDataset is also accepted for training. Provide model inputs and the targets needed to compute your task's loss. For streaming data without __len__, set max_steps.
2. Choose the model and its matching tokenizer/processor. For text, tokenize your text column with dataset.map(..., batched=True), truncate to an appropriate maximum length, and remove unneeded original columns. Create separate training and validation/test splits.
3. Choose a data collator for the task. The official causal-language-model example uses DataCollatorForLanguageModeling(tokenizer, mlm=False), which dynamically pads batches.
4. Create TrainingArguments, construct Trainer with train_dataset and eval_dataset, and call train(). Use evaluate() for evaluation and save_model() to save locally. Publishing to the Hub is a separate optional action.

Example adaptation of the official tutorial: custom_dataset below is your own Hugging Face Dataset with a "text" column. This is a usage example, not an executed training run.

```python
from transformers import (
    AutoTokenizer, AutoModelForCausalLM,
    DataCollatorForLanguageModeling, TrainingArguments, Trainer,
)

checkpoint = "Qwen/Qwen3-0.6B"
tokenizer = AutoTokenizer.from_pretrained(checkpoint)

def tokenize(batch):
    return tokenizer(batch["text"], truncation=True, max_length=512)

data = custom_dataset.map(
    tokenize, batched=True, remove_columns=custom_dataset.column_names
).train_test_split(test_size=0.1)

model = AutoModelForCausalLM.from_pretrained(checkpoint, dtype="auto")
args = TrainingArguments(
    output_dir="custom-model",
    num_train_epochs=3,
    per_device_train_batch_size=2,
    learning_rate=2e-5,
    eval_strategy="epoch",
    save_strategy="epoch",
    load_best_model_at_end=True,
)
trainer = Trainer(
    model=model,
    args=args,
    train_dataset=data["train"],
    eval_dataset=data["test"],
    processing_class=tokenizer,
    data_collator=DataCollatorForLanguageModeling(tokenizer, mlm=False),
)
trainer.train()
trainer.evaluate()
trainer.save_model("custom-model")
```

Trainer constructor parameters
All have a signature default of None except optimizers, whose default is (None, None). Some None values trigger defaults or requirements described here.

| Parameter | What it configures |
| --- | --- |
| model | Model to train/evaluate/predict with: PreTrainedModel or compatible torch.nn.Module. Supply model or model_init. |
| args | TrainingArguments for the training run; if omitted, Trainer creates basic arguments with output_dir="tmp_trainer". |
| data_collator | Function assembling dataset examples into a batch; defaults to default_data_collator, or DataCollatorWithPadding when a tokenizer/feature extractor is supplied. |
| train_dataset | Training Dataset or IterableDataset. |
| eval_dataset | Evaluation Dataset, or a dictionary of named datasets evaluated separately. |
| processing_class | Tokenizer, image processor, feature extractor, or processor; saved with the model. |
| model_init | Callable creating a fresh model for each train() call; may accept a hyperparameter-search trial. |
| compute_loss_func | Custom loss function receiving model outputs, labels, and the number of items in the accumulated batch. |
| compute_metrics | Evaluation function taking EvalPrediction and returning a metric dictionary. With batch_eval_metrics=True, it must also accept compute_result. |
| callbacks | Additional TrainerCallback hooks for training events, added to default callbacks. |
| optimizers | Custom (optimizer, learning-rate scheduler) tuple; otherwise Trainer supplies AdamW and a linear schedule with warmup controlled by args. |
| optimizer_cls_and_kwargs | Optimizer class and keyword arguments; overrides args.optim/optim_args and cannot be combined with optimizers. |
| preprocess_logits_for_metrics | Transforms logits before evaluation caching and before they reach compute_metrics. |

TrainingArguments is a separate configuration object. Common settings demonstrated by the guide include output_dir, num_train_epochs, per_device_train_batch_size, learning_rate, gradient_accumulation_steps, gradient_checkpointing, gradient_checkpointing_kwargs, bf16, logging_steps, eval_strategy, save_strategy, and load_best_model_at_end. The guide's example values are 3 epochs, batch size 2 per device, learning rate 2e-5, accumulation 8, logging every 10 steps, and evaluation/saving each epoch; these are example choices, not required values or defaults.
